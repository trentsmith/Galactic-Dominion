Galactic Dominion v0.9 adds Cinderbit and a matching Comet Pup Interceptor appearance, inspired by the supplied reference. Both have red-and-pearl armor, pointed ears, glowing paw pods and sculpted flame tails. The companion has crescent eyes, an open-mouth expression and a swishing tail.

Research **Cinderbit — Comet Pup** for **140 salvage** and equip it in Crew to fire **Meteor Nuzzle**, fast amber sparks (9 damage, two-second cooldown, 260m range). Research **Cinderbit Scout** for **200 salvage** and equip it in an Interceptor’s Variant slot. The ship appearance is cosmetic. Existing saves and Legendary/Mythic drop ticket odds are retained.

**3D models:** download Galactic-Dominion-3D-Models.zip for all eleven models in GLB and self-contained Godot scene formats, including both new additions. The exports are static meshes; game scripts animate eyes, wings, tails and orbiting.

**Players:** download Galactic-Dominion-Windows.zip, extract it, and run GalacticDominion.exe. Godot and Python are not needed. Choose Free Roam for solo play, or Online to join your host.

**Host on your Windows PC:** download Galactic-Dominion-Server-Windows.zip, extract it, and double-click Start-Server-Windows.bat. The host download includes the game engine and a portable Python runtime. Keep the server window open. It displays your LAN address for friends on the same network.

**Join:** enter the host's LAN address in the combat address field, click Use This Address For A Local-Network Host, create/sign into your account, and Join Open Arena. Ready up; the first pilot launches Free Roam or Fleet Royale. Free-roam sessions accept later joins.

The server and all clients must use this v0.9 build. Local and online collections stay separate. This alpha supports six human pilot slots per server plus AI; it is not a public worldwide service. Internet hosting needs router/VPS configuration and HTTPS for the account API; see the included hosting instructions.

Linux player and server downloads and SHA256 checksums are also included. Windows exports are produced by Godot; Windows GUI execution has not been tested in the Linux development environment.
