Galactic Dominion v0.18 improves **the beauty of space and the fleet**.

- Soft teal/indigo nebulae, warm/cool stars and subtle distant galactic haze.
- Detailed ocean/coast terrain, independent drifting cloud shells, blue atmospheric rims and finely banded rings with a gap.
- Irregular cratered asteroids with mineral shading; wrecks have severed conduits, exposed panels and empty engine chambers.
- Sculpted ship decks, layered armor, vents, glass cockpits, gold seams, shaped wings and tapered exhausts for all five classes and every livery.
- Better Hangar framing, warm/cool lighting and antialiasing. Existing saves, unlocks and all-class skin compatibility remain intact.
- Updated **83 GLBs and 83 bundled Godot model scenes**.

**Play:** extract Galactic-Dominion-Windows.zip and run GalacticDominion.exe. Choose **Peaceful Flight**, then press **H** to hide the HUD and enjoy the scenery. Normal combat modes retain their rules and obstacles.

**Host:** update all clients and the self-hosted server to v0.18. Extract Galactic-Dominion-Server-Windows.zip and run Start-Server-Windows.bat. Linux builds, models and checksums are included.

Native Godot/OpenGL renders were inspected. Windows GUI execution remains untested on the Linux development machine. Procedural planet materials require Godot to render; portable GLB ship exports use standard materials. This remains a six-player self-hosted alpha.
